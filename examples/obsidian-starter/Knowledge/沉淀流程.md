# 沉淀流程

目标：对话结束时，记忆变成可检索的图谱节点，而不是又一篇长日记。

## 四步

1. **扫**：对话里有哪些值得以后再用的点？
2. **拆**：每个点能否用短标题命名？能则一则笔记
3. **写**：按 [[笔记模板]]，先一句话核心，再补展开
4. **链**：接到 [[00 认知库]]、领域枢纽、或已有相关笔记

## 什么该沉淀

- 形成了判断（选 A 不选 B，以及为什么）
- 学到可复用方法 / 模式
- 澄清了一个概念的边界
- 确认了关键事实（账号、架构、约束）

## 什么不该沉淀

- 临时调试过程、一次性命令
- 未成形的碎碎念
- 整段聊天复制

## 和 Agent 协作时的口令（可直接说）

- `沉淀` — 把本次对话拆成短标题笔记
- `沉淀：xxx` — 只沉淀指定主题
- `补链` — 给已有笔记补双链
- `合并：A / B` — 同义笔记合并
