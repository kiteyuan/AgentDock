# 工作区约定

> 一句话核心：`workspace/` 是 Agent 默认工作区，也是你的 Obsidian 库根目录。

## 约定

- **个人知识库**放在仓库根目录 `workspace/`（git 已忽略，勿提交）
- Runtime 在 `config.yaml` 的 `workspace.root` 配置，并经协议字段 `workspace` 下发给各 Agent
- **参考模板**在 `examples/obsidian-starter/`（可复制到空的 `workspace/`）
- 换目录：改 `config.yaml`，或单网关临时用 `PI_CWD`（仅当请求未带 workspace）
